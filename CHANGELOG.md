# Changelog

## 1.0.0
- Initial release: TextMate grammar (AT&T + `.intel_syntax` regions), semantic highlighting,

  signature help, go-to-definition (incl. `1b`/`1f`), references, rename, outline, folding,
  document links, formatter, quick fixes, built-in checks, `as`-backed diagnostics, build/run/disassemble commands.
